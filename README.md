# Who's That Pokémon?

[![Vercel Deployment](https://vercel.com/button)](https://whos-that-pokemon-zeta.vercel.app)

"Who's That Pokémon?" is an interactive web application that challenges users to identify Pokémon based on their silhouettes, reminiscent of the classic game from the Pokémon series.

## 📸 Demo

Experience the live version of the application:

🔗 [whos-that-pokemon-zeta.vercel.app](https://whos-that-pokemon-zeta.vercel.app)

## 🎮 Features

- 🧠 Guess the Pokémon based on a dark silhouette
- 🟢 Instant feedback: Right or Wrong
- 🔄 Get a new Pokémon with one click
- 📱 Fully responsive for mobile & desktop

## 🛠️ Installation

To set up the project locally:

```bash
git clone https://github.com/SaadArqam/Whos-That-Pokemon.git
cd Whos-That-Pokemon
npm install

npm run dev
